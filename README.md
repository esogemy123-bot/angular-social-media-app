# 🚀 Angular Social Media Application

A modern, highly responsive social media web application built with Angular, designed to connect users, share posts, and interact seamlessly with advanced UI/UX features.

🔗 **Live Demo:** [View Live Site](https://angular-social-media-bn7i9fc83-esraa9.vercel.app/)
💻 **GitHub Repository:** [GitHub Repository](https://github.com/esogemy123-bot/angular-social-media-app)

---

## ✨ Features

- **User Authentication:** Secure login and registration flow.
- **Feed & Post Management:** Create, view, like, and comment on posts dynamically.
- **Dark / Light Mode:** Fully customizable theme switching based on user preference, with state persistence using `localStorage`.
- **Responsive UI & Custom Drawers:** Clean & modern design optimized for all screen sizes featuring custom mobile navigation drawers and smooth transitions with `overflow-x` handling.
- **Modern Styling:** Built with advanced utility classes and custom layouts for an exceptional user experience.

* **Multi-Language Support (i18n):** Fully localized and supports **5 different languages**, allowing users to seamlessly switch between languages for a personalized experience.

---

## 🛠️ Tech Stack

- **Framework:** Angular & TypeScript
- **Styling:** Tailwind CSS & Flowbite
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
